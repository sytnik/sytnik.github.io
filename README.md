# Oleh Sytnik — Personal CV Website

Online interactive curriculum vitae and professional portfolio of Oleh Sytnik, hosted at [sytnik.github.io](https://sytnik.github.io).

## Tech Stack

- **Framework:** Angular 22 (Standalone components, modern control flow, lazy-loaded routes)
- **Styling:** Tailwind CSS 3.4.4
- **Hosting:** GitHub Pages (served from `/docs`)

## Quick Start

```bash
cd SytnikGithub

# Install dependencies
npm install

# Start local development server (http://localhost:4200)
npm start -- --port 4200

# Build for production (outputs to ../docs)
npm run build
```
